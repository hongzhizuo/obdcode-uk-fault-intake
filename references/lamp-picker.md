# Lamp picker

Reply with the **number** (1–13) or the `id`.
If none match, say so — do not pick the closest.
Blue/green status lights (main beam, indicators, cruise, fog, engine-cold) are not faults and are not on this list.
If they are driving and the lamp is 1, 2, 3, 7, or 8-with-heavy-steering/rising-temp/belt-noise: stop first. The picker does not delay that.

1. `oil-pressure` — Red oil-can (sometimes with a drip). Engine oil is not at pressure. **Stop.**
2. `coolant-temp` — Red thermometer in wavy liquid (hot). Engine overheating. **Stop.** (Blue version of the same symbol = still cold, not a fault.)
3. `brake-system` — Red `!` in a circle in brackets, or the word BRAKE. Check handbrake first; if still on, **Stop.**
4. `airbag-srs` — Red seated person with a circle in front. Airbag/seatbelt pretensioner fault. Limited driving to get it fixed. No owner repair.
5. `power-steering` — Red or amber steering wheel with `!`. If steering has gone heavy, **Stop.** If lamp only, limited driving.
6. `engine-steady` — Amber engine-block outline, **steady**. Drive with care; get the code read. Does not name the fault.
7. `engine-flashing` — Same engine outline, **flashing**, often with judder. Active misfire. **Stop.**
8. `battery-charging` — Red battery `+/-`. Charging system, not "fit a new battery". Limited driving; **Stop** if steering goes heavy, temp rises, or belt noise.
9. `dpf` — Amber exhaust box with dots. Diesel only. Filter not clearing. Limited; do not keep repeating regen drives if flashing/limp/oil rising.
10. `tyre-pressure` — Amber horseshoe tyre with `!`. Usually low pressure (owner can fix). Flash-then-steady at startup ≈ sensor/system fault.
11. `abs` — Amber `ABS` in a circle. Normal brakes work, anti-lock does not. Limited, extra stopping distance.
12. `esc-traction` — Amber car with skid lines. **Flashing while driving is normal** (system working). **Steady** = off or faulty (check the traction button first).
13. `glow-plug` — Amber coiled spiral. Diesel. Coming on with ignition then going out is **normal**. Stays on after start, or flashes, is a fault.

Accept number, id, or a clear paraphrase that maps to exactly one row (e.g. "yellow engine light not flashing" → 6).
If ambiguous between 6 and 7, ask only: steady or flashing?
If ambiguous between 12 flashing vs steady, ask only that.
Never map a free-text "a light came on" to a default lamp.
