# Lamp picker

Owners recognise **shapes on the cluster**, not names like "oil-pressure". Always show this drawing. Never replace it with a prose list.

Paste the cluster **in a fenced code block** so the characters line up. Ask: "Which number matches the lamp that is lit? Reply 1–13. If it is flashing, say flashing."

If they are driving and the lamp is 1, 2, 3, 7, or 8-with-heavy-steering/rising-temp/belt-noise: **stop first**. This drawing does not delay that.

Blue/green lights (main beam, indicators, cruise, fog, engine-cold) are not on this cluster. If none match, say so — do not pick the closest.

Legend (same numbers):

1. `oil-pressure` — red oil-can, sometimes with a drip. **Stop.**
2. `coolant-temp` — red thermometer in waves (hot). **Stop.** Blue version of the same symbol = still cold, not a fault.
3. `brake-system` — red `!` in a circle, or the word BRAKE. Check handbrake first; if still on, **Stop.**
4. `airbag-srs` — red seated person with a circle. Limited driving to get it fixed. No owner repair.
5. `power-steering` — red or amber steering wheel with `!`. If steering has gone heavy, **Stop.** If lamp only, limited driving.
6. `engine-steady` — amber engine-block outline, **steady**. Drive with care. Does not name the fault.
7. `engine-flashing` — same engine outline, **flashing**, often with judder. **Stop.**
8. `battery-charging` — red battery `+/-`. Not "fit a new battery". Limited; **Stop** if steering goes heavy, temp rises, or belt noise.
9. `dpf` — amber exhaust box with dots. Diesel only. Limited.
10. `tyre-pressure` — amber horseshoe tyre with `!`. Usually low pressure.
11. `abs` — amber `ABS` in a circle. Normal brakes work; anti-lock does not.
12. `esc-traction` — amber car with skid lines. **Flashing while driving is normal.** **Steady** = off or faulty.
13. `glow-plug` — amber coiled spiral. Diesel. Coming on with ignition then going out is **normal**.

Accept number, id, or "the engine shape, not flashing". If 6 vs 7 is unclear, ask only: steady or flashing? If 12 is unclear, ask only: flashing or steady? Never map "a light came on" to a default lamp.
