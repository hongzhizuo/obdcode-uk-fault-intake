# Never clear a lamp; never scan-tool forced regen

Not a second SKILL. If this file disagrees with `SKILL.md`, `references/prognosis.md`, `references/prognosis-cards.md`, or `references/value-gain.md`, those four win.

Clearing a lamp and a scan-tool forced DPF regen are never close-it-yourself. A **handbook** regeneration drive on a **diesel** DPF, when the lamp is **steady** and the car is **driving normally**, is a different, allowed owner path. Do not mix the three.

## When

Use this note when the owner wants the light **gone** by wiping data or by a diagnostic-tool DPF burn, including:

- “Clear the codes / reset the ECU / erase the lamp and see if it comes back”
- A reader is already connected and they ask whether to press Clear
- Close-it-yourself on `engine-steady` or unmatched petrol / hybrid GPF (read and write down; do not clear)
- Diesel `dpf` when they ask for a **forced / service / parked / scan-tool** regeneration
- Airbag, ABS, or TPMS **malfunction**: a scan-clear is not a repair
- They treat “regen” as the same act as clearing the DPF lamp

Do **not** refuse these allowed owner paths as if they were a scan-clear:

- Diesel `dpf`, **steady**, car **driving normally**: **one** handbook regeneration drive
- TPMS simply on: inflate to the **placard**, then the handbook reset
- ESC: traction button back on if they had switched it off
- Not-a-fault endings (glow 13 went out, blue thermometer that went out, parking-brake brake lamp, ESC flashing while driving): skip outlook

Petrol / hybrid GPF is not diesel DPF: no handbook regen copy.

Flash / limp / oil over maximum on diesel DPF is `poor` on the DPF card — no more loops, no forced regen, no clear.

## Owner copy

Do not clear the lamp or erase the stored codes. That is not a repair. It hides the freeze frame the garage needs. If you have a small reader, read the stored codes and freeze frame, write them down, and leave them stored.

Do not run a scan-tool forced DPF regeneration. That is not an owner job.

If this is a diesel with a steady DPF lamp and the car still drives normally, one handbook regeneration drive — speed, gear and duration in that handbook — outdoors, once. If it flashes, limp, a red warning, or oil over maximum: no more loops; arrange recovery. Do not remove the filter.

## Red lines

- Never advise clearing a lamp as a fix (SKILL red line 4). Stored codes and freeze frame stay stored.
- Never describe a scan-tool forced DPF regen (menus, temperatures, parked idle burns, “service regen” steps) — not even as “tell the garage to run one.” Garage speech is soot load and differential pressure, then `dpf-cleaning-cost` if that path applies.
- Handbook regen is **not** that act: one drive from **this car’s handbook**, diesel DPF only, steady lamp, driving normally, **once**, not in an enclosed space (carbon monoxide).
- Do not give diesel regen copy on petrol / hybrid GPF.
- No how-to for DPF / GPF / cat delete, remap, or cutting the filter out. Illegal-work sale effect is a Value-gain **Negative** band, not this file.
- A reader does not fix oil, hot coolant, hydraulic brakes, airbags, or a flashing engine lamp — and clearing those lamps is still not a fix.
- TPMS handbook reset after correct pressures is not a scan-tool clear. Do not refuse it as if it were.
- Do not invent pounds. Do not diagnose. Do not print a plate. Do not add a 14th lamp id.
- Device and shop links stay below Stop / recovery.

## Pass / fail

**Pass:** “Write stored codes and freeze frame down. Do not clear.”

**Pass:** “Clearing the lamp is not a repair.”

**Pass:** “One handbook regen if this diesel is driving normally. Not a scan-tool forced regen.”

**Pass:** “If it flashes, limp, a red warning, or oil over maximum: no more loops — recovery.”

**Pass:** Refuse delete with legal / MOT / sale effect only, no steps.

**Fail:** “Clear it and see if it comes back.”

**Fail:** Forced-regen menus, parked service regen, or “use your scanner to burn the DPF.”

**Fail:** Motorway / handbook regen copy on petrol GPF.

**Fail:** “Just cut the filter out,” or any delete how-to.

**Fail:** Repeating motorway runs on flashing DPF / limp / oil over max.

**Fail:** Scan-clear as an airbag or TPMS-malfunction fix.

**Fail:** Treating handbook regen as forbidden because clearing is forbidden.
